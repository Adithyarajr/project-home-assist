# project-home-assist
an application that lets users find, verify, book and manage house help, cooks, nannies and other home services.

## Overview
Project Home Assist is a web and mobile application designed to simplify the process of finding, managing, and hiring trusted domestic helpers such as maids, cooks, nannies, drivers, and caretakers.

## Problem Statement
Finding reliable domestic help is often fragmented and unverified. This platform provides a centralized, secure, and transparent way to connect households with verified service professionals.

## Objectives
•⁠  ⁠Maintain a database of domestic helpers.
•⁠  ⁠Register and verify service providers.
•⁠  ⁠Search and filter by location, skills, and availability.
•⁠  ⁠Manage bookings and schedules.
•⁠  ⁠Enable ratings and reviews.
•⁠  ⁠Support secure communication and notifications.
